# 太阳视运动

轻量、双色、完全离线的太阳位置与轨迹工具。无需安装，不生成或加载美术资源。

## 打开

双击 `dist/index.html`，用 Edge、Chrome 或 Firefox 打开。该文件包含所有样式、脚本与计算库，可以单独复制给其他人；运行不需要网络、本地服务器、Node.js 或 Python。

## 使用

- 默认地点为北京。输入纬度（−90°～90°）和经度（−180°～180°），点击“应用”或按 Enter 更新地点；北纬、东经为正，南纬、西经为负。“恢复北京”一键还原默认地点。每次打开软件都从北京启动。
- 切换地点同步更新太阳角度、天空轨迹、地球观测点、日出日落、昼长与全年日期标注，保留所选日期、时刻、视角和实时跟随状态，并暂停播放。不同地点均按北京时间 UTC+8 显示；经纬度不会自动改变时区。
- 启动默认勾选“跟随当前时间”，每秒读取当前北京时间并更新位置；跨午夜时自动更新日期、当天轨迹与日出日落，跨年时重新计算全年标注。返回前台时立即校准，不累计后台计时误差。
- 日期滑块覆盖当前年份，步长一天，支持闰年的 366 天。拖动日期保留时分秒，方便比较同一时刻在不同季节的位置。
- 时间滑块覆盖 00:00:00—23:59:59，也可以直接输入准确日期和时分秒。
- 半球视图可拖动旋转，或聚焦画布后用方向键旋转；“复位视角”恢复初始方向。
- 平面天空图北上、东右，圆心为天顶，粗圆为地平线。30°、60°高度用点划网格表示。
- 默认只绘制地平线以上的轨迹。勾选“显示地下轨迹”后，地下部分以虚线显示，当前地下太阳以空心点显示。在平面图中，地下轨迹位于地平线圆外。
- 播放循环当前一天。拖动滑块或手动修改日期、时间时暂停。页面进入后台也暂停。
- 两个视图共用时间、日期与地下轨迹设置。三维视角在模式切换后保留。
- 时间轴标注当天全部日出、日落；日期轴标注所选地点、年份的昼最长、昼最短以及存在的昼夜近等长日期。部分地区全年没有 12 小时昼长的交点，此时不标注近等长日期；极昼、极夜的极值平台取首个日期。点击标注可跳转，悬停可查看详细时刻或昼长。全年结果按地点、年份分批计算并缓存，切换地点不会混用旧数据。
- 左侧地球的地轴默认倾斜一个黄赤交角（约 23.4°），两端标注 N、S。拖动时间轴时地球绕这根轴自转；拖动日期轴时太阳方向与轨迹更新，地轴保持原来的朝向。拖动地球或用方向键可以自由改变观察角度，不再约束黄道面水平；“复位”恢复默认倾角和观察方向。圈点为当前直射点，粗线为当天直射点近似轨迹，点划线为昼夜分界，虚线表示球体背面。浅色模式轻微压暗夜面，深色模式轻微提亮昼面，两种模式均保持昼面较亮、夜面较暗。
- 地球表面的方点代表当前观测地点，其放大小半球沿当地天顶朝外，底圈代表当地地平面，与右侧“当地天空”对应。小半球大小仅用于示意，白天还显示当前太阳方向。地球画布除了地轴的 N、S，只绘制几何图形；说明保留在图外的图例与计算约定中。
- 手动修改日期、年份或时间、拖动滑块、点击日出日落与全年日期标注，或开始播放，均自动关闭跟随。取消勾选可冻结时刻；“回到当前”或重新勾选会恢复日期、时刻并继续跟随。切换天空视图、主题及旋转模型不关闭跟随。
- 浅色／深色互换同一组两种颜色，优先沿用用户在本工具中保存的选择。

## 计算约定

默认地点为北京：39.9042° N、116.4074° E，可输入全球任意有效经纬度，海拔统一取 0 米。所有日期使用固定北京时间 UTC+8，不自动采用所在地时区，也不模拟历史时区及夏令时。输入年份范围 1900—2100，采用格里高利历。

计算使用 [Astronomy Engine 2.1.19](https://github.com/cosinekitty/astronomy/tree/v2.1.19)（MIT），其截断 VSOP87 模型及观测坐标转换随软件保存，不调用在线服务。保留上游许可，见 `vendor/LICENSE`，单文件版本也包含上游许可声明。

太阳位置采用当地观测者的太阳中心视位置，包括库提供的岁差、章动、视差和光行差处理，不加大气折射。方位角以正北 0° 起，顺时针递增；高度角以地平线 0°、天顶 90° 定义。显示到 0.1°并不意味着对每个时刻保证 0.1°的实际观测误差。

当天轨迹每两分钟采样，并在高度穿过 0°处通过二分求交加点，防止地平线附近连接误差。当前太阳点按所选时刻独立计算。日出日落使用库的事件搜索，采用太阳上缘和标准折射，显示到分钟；日出时太阳中心的无折射高度约为 −0.83°，所以日出日落并非绘制轨迹的 0°交点。忽略山体、建筑遮挡及实际天气变化。

平面投影为方位等距投影：`r = R × (90 − h) / 90`，`x = cx + r × sin(A)`，`y = cy − r × cos(A)`。三维视图把同一组角度转换为东、北、上单位向量，经视角旋转后作正交投影。可视化不影响计算结果。

昼长统计所选北京时间自然日 00:00—24:00 内的全部日照区间，支持日落早于日出、跨午夜、只出现一次日出或日落，以及高纬过渡日的多次交点。日出、日落读数显示当天首次事件，时间轴标注全部事件；全天无日出日落时显示极昼或极夜。全年日期标注按这些自然日的日照时长计算，昼最长、昼最短选全年极值；昼夜近等长日期在昼长跨过 12 小时的相邻日期中选最接近者，不采用春分、秋分日期替代，也不补造不存在的交点。日照时长显示至秒可在标注提示中查看。

地球采用理想球体，其直射点是辅助近似：使用当日地心视赤纬作为纬度，以 `15 × (太阳赤经 − 格林尼治视恒星时)` 求东经，再归一化至 −180°—180°。当天轨迹覆盖北京时间 00:00 至次日 00:00，每 10 分钟重新计算一次，经度绕回不在平面上直接连接，而先映射到球面。昼夜分界是与太阳方向垂直的球面大圆，忽略折射、太阳圆面和地球扁率；这些辅助绘图不修改右侧所选地点的太阳位置或日出日落计算。直射点本身与观测地点无关，切换地点只移动地球上的当地小半球。

地球绘图按格林尼治视恒星时构造绕地轴的自转角，包括一天约 360.99°的恒星自转。启动时保存库的 `Rotation_EQD_ECT` 矩阵，用其黄赤交角确定辅助球体约 23.4°的倾角；该矩阵在修改日期、时间时保持不变，使 N、S 朝向严格固定。辅助模型忽略此后跨日期的微小黄赤交角变化，不影响右侧太阳角度、直射点坐标和事件计算。默认相机沿参考坐标的 X 方向观察，使地轴的屏幕倾角等于黄赤交角；自由视角以屏幕轴的旋转矩阵累积，不以黄道面或太阳方向为竖直参照。当地小半球使用同一套当地东、北、上向量构造，底圈与球面在观测点相切，示意半径放大至地球半径的 28%，底面略抬高以便辨认。昼夜填充以球面法向量与太阳方向的点积符号划分，仅用主题的两种底色进行淡色叠加，不引入图片或渐变。

## 修改与扩展

源码按职责组织：

| 文件 | 职责 |
| --- | --- |
| `index.html` | 页面和控件 |
| `src/style.css` | 双色主题与响应式布局 |
| `src/time.js` | UTC+8、日期、闰年和时间转换 |
| `src/solar.js` | 位置、轨迹、日出日落、全年昼长标注与直射点；接受任意地点参数 |
| `src/projection.js` | 半球、平面、地球黄道坐标与当地小半球映射 |
| `src/view.js` | Canvas 几何绘图与视角旋转 |
| `src/earth.js` | 地球线框、直射点轨迹、昼夜分界与独立旋转 |
| `src/app.js` | 经纬度选择、界面状态、实时跟随、滑块、播放和地点缓存 |
| `vendor/` | 固定版本计算库与许可证 |
| `scripts/` | 离线打包和可选本地预览 |
| `tests/` | 时间、投影、轨迹、日出日落与独立参考验证 |

修改源码后，使用 Node.js 18 或以上运行：

```sh
node scripts/build.cjs
node --test tests/*.test.cjs
```

无需安装 npm 依赖。可选本地预览：`node scripts/serve.cjs`，访问打印的本地地址。正常使用请直接打开离线 HTML。

当前已支持全球经纬度和跨午夜日照，统一采用 UTC+8。下一步可扩展独立时区选择、所在地本地日期、海拔或城市预设。新增其他天体可沿用计算库，但需增加相应的绘图与界面规则。

## 验证依据

独立太阳角度参考来自 [NREL/TP-560-34302，附录 A.5、表 A5.1](https://docs.nlr.gov/docs/fy08osti/34302.pdf)：2003-10-17 12:30:30 UTC−7，Golden Colorado，纬度 39.742476°，经度 −105.1786°，海拔 1830.14 米。核对方位角，并由报告公布的站心赤纬和时角独立推导无折射高度角，容差为 0.02°。这一公开算例验证不等同于对全部年份的独立精度认证。

其他自动检查覆盖 UTC+8 日期边界、世纪闰年、支持年份首尾、季节轨迹、地平线交点、太阳过中天、标准日出定义、极昼极夜，以及单文件的离线完整性。新增检查还覆盖直射点对照同一公开算例、直射点近似天顶条件、一天轨迹跨 ±180° 经度的球面连续性、昼夜分界与太阳方向的垂直关系，以及跨世纪、闰年下全年极值与近等长日期的选择。

地球检查覆盖跨季节与支持年份首尾的天文黄赤交角、坐标变换保持夹角、当地小半球的相切与方向约定，以及实际绘图中的默认地轴倾角、日期与时间变化时地轴固定、时间变化带动绕轴自转、自由视角不锁定黄道面和 N、S 标注。实时跟随使用可控时钟运行实际界面控制器，验证默认开启、跨午夜跨年、手动控制和播放退出跟随、返回前台校准与恢复跟随。

全球地点检查覆盖东西经边界、南北极、南半球季节、跨北京时间午夜的日照、极昼极夜过渡日和多次交点。实际界面控制器还验证默认北京、切换地点后的角度与轨迹、全年标注异步取消及缓存隔离、无效输入、恢复北京和实时跟随状态。
