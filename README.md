# 太阳视运动

离线太阳位置与轨迹工具，使用几何线条绘制天空和地球示意图。

## 使用说明

用 Edge、Chrome 或 Firefox 直接打开 `dist/index.html`，无需联网。

- 默认地点为北京，可输入经纬度并点击“应用”；北纬、东经为正，南纬、西经为负。
- 启动时跟随当前时间。拖动日期、时间滑块或开始播放会关闭跟随；“回到当前”恢复跟随。
- 可切换半球／平面视图、浅色／深色模式；半球和地球可拖动旋转。
- 时间轴标注日出、日落，日期轴标注昼最长、昼最短和存在的昼夜近等长日期，点击可跳转。
- 所有地点均使用北京时间 UTC+8，支持 1900—2100 年。

修改源码后，需要 Node.js 18 或以上，无需安装 npm 依赖：

```sh
node scripts/build.cjs
```

此命令更新离线成品。可用 `node --test tests/*.test.cjs` 检查计算，用 `node scripts/serve.cjs` 启动本地预览。

## 计算依据

使用 [Astronomy Engine 2.1.19](https://github.com/cosinekitty/astronomy/tree/v2.1.19) 的截断 VSOP87 模型及坐标转换，包含岁差、章动、视差和光行差处理。默认北京坐标为 39.9042° N、116.4074° E，所有地点海拔取 0 米。

太阳角度和天空轨迹使用太阳中心的无折射视位置：方位角从正北起顺时针计量，高度角以地平线为 0°。轨迹每两分钟采样，并补算地平线交点。日出日落采用太阳上缘和标准大气折射，忽略地形、建筑与天气影响，因此不等同于轨迹的 0°交点。

昼长为所选 UTC+8 自然日内全部日照区间之和；全年极值确定昼最长、昼最短日期，昼长跨过 12 小时时选最接近的日期标注近等长，不直接使用春分、秋分替代。

平面图采用方位等距投影，半球图将太阳方向转换为当地东、北、上向量后作正交投影。地球为辅助球体：直射点纬度取地心视赤纬，经度由太阳赤经与格林尼治视恒星时求得，当天轨迹每 10 分钟采样；地轴保持启动时约 23.4°的倾角，绕轴旋转按视恒星时计算。
